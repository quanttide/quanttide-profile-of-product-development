# QtCloud Read（量潮阅读云）

## 定位

还没有想好上线的到底是"量潮阅读"还是"量潮阅读云"：前者压力比较小，随便写出来就可以；但从定位上来讲，更想要的还是团队协作的阅读器，所以更想做一个"云"。阅读云不提供内容，而是提供平台——这样绕开 C 端阅读的版权问题（阅读器好做，但版权很难做）。

## 核心目标

从 C 端形态开始演化：先做一个阅读器，里面没有任何内容，只把自己想读的东西装进去；然后不断看我们需要什么团队协作功能，逐步长成阅读云。

## 阶段方法

- **阅读器先行**：先做阅读器形态（压力小），装自己想读的内容，甚至可以直接兼容自己的文档格式
- **协作演化**：按需增加团队协作功能，逐步演进为团队协作的阅读云

## 数据驱动

从自己的阅读使用中看需要什么协作功能——先自己用起来，再决定长成什么样。

## 需求与 AI

明确性即"读得起来"：能把自己想读的东西装进阅读器、读起来，就是明确的；连读都读不起来，就是模糊的。
