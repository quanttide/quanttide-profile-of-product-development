# QtCloud Course（量潮课程云）

## 定位：课程的研发与交付平台

课程云是量潮课程的研发与交付平台：课程在这里被生产（分解 → 制作 → 审核 → 组合），也在这里被学习（学员上课）。课程是量潮的盈利重点，课程云承载这条主盈利链的产品形态。

与众包云（qtcrowd）的协同：qtcrowd 提供众包供给（接单人、信用、竞价），**交付过程在课程云内完成**——录制、审核、组合都在课程云里进行，由平台集中管理。接单人未来在课程云做这些事，交付过程受平台集中管理，同时促活课程云平台。

## 核心目标：课程研发进入最小循环

- **有人制作、有人审核**：课程研发的最小循环——制作（录片段）与审核（学习记录）由不同的人承担，平台负责分解与组合
- **众包供给接入**：录制与审核任务由众包完成，接单人在课程云内交付，交付过程集中管理
- **盈利重点落地**：课程是盈利端，课程云是盈利链的产品承载——众包成本（现金/代金券）与课程收入在课程云内闭环

## 阶段方法：课程研发最小循环

- **分解**（平台内部）：按知识点切 2-5 分钟片段，产出三件套（片段目标 + 录制提纲 + 验收要点），提纲写到"录制者不需要理解课程就能录"的程度
- **制作**（众包）：录制者照提纲录屏讲解 2-5 分钟（无需出镜），在课程云内交付
- **审核**（众包）：审核者跟着视频学习出记录——审核者就是课程的第一个学生，能学会 = 视频合格
- **判断**（平台）：规则预先定死（覆盖要点 ≥ 阈值、无硬伤），AI 比对 + 人抽检
- **组合**（平台）：按知识顺序串接，AI 拼接、人审结果；片段先进素材库，再组合成节、节组成课

## 数据驱动

课程生产数据是核心：录制通过率（录制者信用）、审核记录（视频质量信号）、组合结果（课程成型度）、代金券消耗（课程额度紧张度）。这些数据驱动课程云的迭代与定价调节。

## 需求与 AI

需求的清晰度 = 能分解成片段、写得出提纲：能拆到"照着讲就行"的粒度就是明确的，拆不出来就是模糊的。AI 承担分解初稿、审核比对、拼接组合，人负责裁决。
