# 量潮文档云用户故事地图

用户画像：需要把散落文档转成 Markdown 并编辑成书的内容工作者。

## 活动：收集文档
### 任务：汇集各处来源的文档
· 用户要把飞书等各种来源的文档收集到一起
### 任务：统一存放待整理的文档
· 用户要把散落各处的文档集中起来以便后续处理

## 活动：转换格式
### 任务：转成 Markdown
· 用户要把现有文档转成 Markdown 格式
### 任务：校验转换结果
· 用户要确认转换后的内容与原文一致

## 活动：编辑成书
### 任务：编排成书
· 用户要把整理好的 Markdown 内容编辑成一本书
### 任务：按叙事需要分流
· 用户要在需要叙事梳理时，把内容交给写作云处理
