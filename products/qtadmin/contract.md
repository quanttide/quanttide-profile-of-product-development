# 产品承诺 · 量潮管理后台 (QtAdmin)

> 面向用户的承诺清单：以下功能按优先级交付。

---

## P0 — 核心闭环

### Studio (可视化界面)

| 功能 | 说明 |
|------|------|
| 多工作区 | 支持创始人/公司等工作区切换 |
| Dashboard | 今日概览，业务决策卡片 + 职能 KPI |
| 咨询管理 (QtConsult) | 双面板决策看板：信息板 + 策略板，完整 CRUD |
| 课堂管理 (QtClass) | 四类课程管理：校企合作/培训基地/内训/1对1 |
| 组织管理 | 员工/部门/岗位浏览 |

### CLI (命令行)

| 功能 | 说明 |
|------|------|
| 人力资源 | 员工/部门/岗位管理，招聘进度追踪 |
| 数字资产管理 | 日志归档、结构合规检查、语义质量评分 |
| 通知分发 | 基于规则的飞书邮件通知 |

## P1 — 重要体验

| 功能 | 说明 | 交付形态 |
|------|------|---------|
| 知识采集 | LLM 从文档中提取知识，构建本体 | CLI |
| 业务线 CRUD | 云资源、数据集、招聘等业务域管理 | Provider API |
| 认知分析 | 认知进化分析报告 | Studio |

## P2 — 体验增强

| 功能 | 说明 | 交付形态 |
|------|------|---------|
| 用户故事地图 | 产品需求画布 | Studio |
| 写作工作台 | 在线写作与编辑 | Studio |
| S3 持久化 | 对象存储替代本地 JSON 文件 | Provider |
