# 产品承诺 · 量潮管理后台 (QtAdmin)

> 面向用户：本文档说明 QtAdmin 提供的功能。

---

## Studio 客户端

Flutter 桌面/Web 应用，提供可视化操作界面。

### 工作区

- 支持多工作区切换（创始人视图、公司视图）

### Dashboard

今日概览面板，展示各业务线关键数据和职能 KPI。

### 业务管理

- **咨询管理** — 双面板决策看板：信息板（发现/沟通） + 策略板（需求/策略/决策链）
- **课堂管理** — 四类课程管理：校企合作、培训基地、内训、1对1

### 组织管理

- 员工、部门、岗位的信息浏览

### 认知分析

- 认知进化分析报告

---

## CLI 工具

Rust 编写的命令行工具，提供自动化操作。

### 数字资产管理

- 日志归档 — 期刊日志的归档管理
- 结构合规检查 — 文件存在性、格式、提交规范校验
- 语义质量评分 — 基于 LLM 从叙事/知识/认知三个维度评分

### 人力资源管理

- 招聘状态追踪
- 岗位管理

### 知识工程

- 基于 LLM 从文档中采集知识
- 从 YAML 本体定义中提取结构化知识产物

### 通知分发

- 基于规则的飞书邮件通知发送

---

## Provider API

Go 编写的 REST API 服务，提供数据接口。

- 员工/部门/岗位的 CRUD
- 业务域（咨询、课堂、云资源、数据集）的 CRUD
- 简历导入与面试创建
- 通知规则与记录管理
