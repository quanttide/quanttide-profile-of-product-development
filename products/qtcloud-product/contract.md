# 产品承诺 · 量潮产品云 (QtCloud Product)

> 面向用户的承诺清单：以下功能按优先级交付。

---

## P0 — 核心闭环

| 功能 | 说明 |
|------|------|
| 用户故事地图画布 | 支持三层结构：用户活动泳道 → 用户任务 → 用户故事 |
| 故事卡拖放 | 长按拖拽故事卡，在泳道/任务间移动 |
| MVP 发布线 | 可拖动的水平红线，区分当前版本与未来迭代 |
| 画布浏览 | 横向滚动浏览完整地图 |

## P1 — 重要体验

| 功能 | 说明 |
|------|------|
| 文档站点 | MyST Markdown 发布 PRD/IxD/ADD 文档 |
| 故事卡详情 | 点击查看/编辑故事卡内容（标题、阶段、状态） |
| 多地图管理 | 创建和管理多个故事地图 |

## P2 — 体验增强

| 功能 | 说明 |
|------|------|
| LLM PRD 辅助 | AI 辅助编写产品需求文档 |
| 协作编辑 | 多人同时编辑同一张地图 |
| 导出 | 导出地图为图片或文档格式 |
