事件总览事件名以代码常量为准

事件中文名聚合触发负载要点
WorkspaceCreated工作区已创建工作区 首次开账本时自动落（Locate::ensure） 仅公共三样；先于账本内一切事件
WorkflowCreated工作流已创建工作流 workflow create / workflow import 声明全文 + 派生凭证
WorkOrderCreated工单已创建工单 order create 工单凭证 + 名字 + 所引工作流 + 工单全文
WorkRecorded工作记录已追加工单 order next（AI 走一步）/ order done（人记一笔） 记录凭证 + 页码 + 步骤凭证 + 记录全文

公共信封落盘于 <账本>/events.jsonl，一条一行

所有事件共享三个公共字段，聚合自有字段随后；时刻为秒级本地时间（字符串比较即时间比较）：

{
  "event": "WorkOrderCreated",
  "at": "2026-09-02T10:30:00",
  "workspace_id": "……",
  "order_id": "……", "name": "……", "workflow_id": "……",
  "order": { "……": "工单 YAML 全文" }
}

事件明细

WorkspaceCreated工作区已创建工作区聚合
触发：任何命令首次触碰账本时，若工作区身份文件不存在则先建身份并落此事件——宁可落盘不可空算。
负载
  • 无附加字段，仅公共三样（event / at / workspace_id）
约束（规范·place/workspace）
  • 先于账本内一切事件——工作流、工单、记录、材料、产物事件均以它为前提；
  • 负载至少携带工作区 id，供下游投影、汇总与审计使用。
WorkflowCreated工作流已创建工作流聚合
触发：qtcloud-work workflow create（新建）与 workflow import（导入）各落一条。
负载
  • workflow_id：派生凭证；
  • name：工作流名；
  • workflow：声明全文（id / name / description / steps[]，每步含 id / name / description / executor / criteria[]，判据含 executor 与 description）。
约束（规范·process/workflow）
  • 负载至少携带工作流名、工作区 id 与 workflow_id——名与号双锚，供下游投影、汇总与审计使用。
WorkOrderCreated工单已创建工单聚合
触发：qtcloud-work order create。
负载
  • order_id：工单凭证；
  • name：工单名；
  • workflow_id：所引工作流凭证；
  • order：工单 YAML 全文（封面）。
约束（规范·process/work-order）
  • 双锚随单走，跨区下游凭 id 直认，凭名字读；
  • 无完结事件：走完没走完是推导，不是事实发生——每一步的发生已由 WorkRecorded 逐条记讫，「完结」由下游吃流水自己投影；
  • 下游按工单 id 去重，重放幂等消化。
WorkRecorded工作记录已追加工单聚合
触发：qtcloud-work order next（AI 执行一步成功后落账）与 order done（人做完记一笔）。
负载
  • order_id / order_name：所属工单双锚；
  • record_id：记录凭证；
  • seq：记录页码；
  • step_id：步骤凭证；
  • record：记录 YAML 全文。
约束（规范·process/work-record）
  • 流水里已双落锚点，事件原样带走，跨区下游凭 step_id 直认，零回查；
  • 只描述追加的那一条，不含全量流水——重建靠事件序列回放，不靠快照覆盖；
  • 下游按记录 id 去重对账，重放幂等消化，不二次落账。

设计约束账本机制

  • 只增不改：事件文件为追加写 JSONL，一条一行；事件名与负载形状由各聚合自定义，公共字段统一在此层补齐。
  • 幂等去重是下游的事：账本只记账，下游按 id 去重——同一 id 的事件重放视作重放。
  • 秒级时刻：不引 chrono，取系统本地时间（%Y-%m-%dT%H:%M:%S），按发生顺序记，字符串比较即时间比较。

与规范的差异规范声明、CLI 尚未落盘的事件

  • WorkspaceUpdated（工作区已更新）——规范·place/workspace 声明，CLI 未实现；
  • MaterialImported（材料已收录）、ArtifactProduced（产物已生成）、ArtifactAccepted（产物已验收）——规范·index 声明，CLI 的材料与产物模块尚未落事件。

规范另以短语记名（如 Workflow Created），代码常量为连写形式，以代码为准。
