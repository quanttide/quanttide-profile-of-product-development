# QtCloud Agent（量潮智能体云）

## 定位

智能体云是量潮智能体体系的治理与沉淀平台：以对话为原料，把承载在智能体里的隐式流程显性化为可复用的资产（skill、上下文、知识）。

**核心命题**：智能体不是从产生对话开始，而是从分析对话开始。分析对话 = 上传、打标签、解释——从人机交互的对话中提取隐性知识并显性化。

## 核心目标

1. **隐式流程显性化**：把智能体对话中承载的个人流程，显性化为可复用、可分享的资产
2. **智能体治理**：评估各智能体的好用程度，明确什么任务用什么智能体，治理智能体产生的数据
3. **对话即资产**：一段对话可以复现流程——对话本身作为资产沉淀

## 阶段方法

### 分析对话（最小循环第一步）

- 导入：第一版先支持 DSH 格式，后续支持其他开源智能体
- 标注：允许人类对上传的对话进行标记（在哪里用、主要功能是什么）
- 解读：对对话进行分析，提炼其中的流程与知识

### 制作 skill（最小循环第二步）

- 从分析好的对话中提取 skill、上下文、知识、harness
- skill 可以在各种平台上使用——构成"分析对话 → 制作 skill"的最小循环

### 治理观测（观测站）

- 智能体在持续观察其他智能体的过程中建立"观测站"：先观测，再提高
- 治理层次：session/message history → skill → harness/loop → plugin
- 从共同处分析（对话怎么分析），找出提升方向

## 数据驱动

- 用观测数据（对话分析结果）找到智能体的结构与优化点
- 分层分工：分析工作（更多语言/文本理解）与执行工作（行动性任务）可由不同模型承担

## 需求与 AI

- 需求明确性：能做出规格、写得出用户故事即明确（对话导入 → 标注 → 解读的流转顺畅即明确）
- 对话分享是必经过程：个人流程 → 团队（脱敏后二次开发成 CLI 等）
