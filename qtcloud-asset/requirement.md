# 量潮资产云用户故事地图

用户画像：需要维护多个第二大脑、把知识结构沉淀为可复用契约的团队。

## 活动：维护 contract

团队把第二大脑的隐性结构显性化为 contract，按需创建、按需维护，让资产结构成为可复用的契约。

### 任务：按需创建

· 用户要按需创建第二大脑的结构，不必一次性建全
· 用户要看到 contract 的边界（在 contract 内的创建是合理的）

### 任务：复用结构

· 用户要学习一个第二大脑的结构，复用到其他第二大脑上
· 用户要维护 contract 并在需要处理时进行必要维护

## 活动：云端接入

contract 放在云端，团队层面通过 API 接入，为管理单位和 contract 单位的管理打下基础。

### 任务：云端托管

· 用户要把 contract 托管在云端（团队通过 API 接入）
· 用户要管理 contract 的访问（管理单位、contract 单位具备管理基础）

### 任务：计量定价

· 用户要按 FaaS 服务的单次成本看到边际价格（如一分钱一个月）
· 用户要能用 contract 费用计算基础设施成本
